## ATS Formatting Tips

### ✅ What This CV Does Right
- **Single-column, plain text layout** — fully parseable by Workday ATS
- **Standard section headings** — Summary, Experience, Skills, Education, Certifications
- **No tables in the main CV body** — avoids ATS parsing failures (tables are only in this README)
- **No images, icons, or graphics** — ATS-safe
- **Keywords used naturally** throughout summary, skills, and experience bullets
- **Quantified achievements** — percentages, record counts, time savings included wherever available
- **Action verbs** — Designed, Built, Engineered, Developed, Led, Optimized, Implemented

### ⚠️ Additional Customization Tips

1. **Submit as `.docx` or clean PDF from Word/Google Docs** — avoid PDF exports from design tools (Canva, InDesign) which embed text as images

3. **Add Kafka/Flink explicitly** to experience if you have hands-on streaming work beyond the Zoomcamp module

6. **Cover letter** — Mention QuantumBlack specifically, reference their AI-first engineering culture, and cite one specific achievement with a number
